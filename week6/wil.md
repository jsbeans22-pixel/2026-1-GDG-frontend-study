# API란?
프론트 / 백엔드가 데이터를 주고받는 통로

예시 코드를 보자면

fetch("https://jsonplaceholder.typicode.com/users/1/todos")
  .then((response) => response.json())
  .then((json) => console.log(json));

fetch() > 서버에 데이터 요청

then() > 데이터가 도착하면 실행할 작업 등록

response.json() > 받아온 JSON 데이터를
자바스크립트가 읽을 수 있도록 JS 객체로 변환

# 비동기 처리
코드 작성 순서대로 작업을 처리하지 않는 것

fetch()를 통해 데이터를 받아오는 작업은 시간이 걸린다.
따라서 이를 기다리는 동안 다른 코드를 먼저 실행하고,
데이터가 도착하면 then()안에 있는 작업을 실행한다!

# Custom Hook
같은 코드가 계속 반복되면..
이를 효율적으로 처리하기 위해서 Custom Hook을 사용
사용자가 직접 hook을 만들어 더욱 효율적으로 코드 작성이 가능하다.

# React Router
페이지를 여러개 만들기 위해 사용한 라이브러리.
다른 방법들도 있으나 React Router는 이중 하나이다.
