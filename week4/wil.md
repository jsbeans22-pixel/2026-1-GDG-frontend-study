# react의 hook 기능
hook의 등장으로 기존 class를 사용하던 시절에서 function만으로 상태 관리가 가능해졌다.
따라서 react 코드가 굉장히 간단해졌다.

1. useState
상태를 저장하는 기능.
이걸 사용하지 않고 일반적으로 변수를 선언하면
react에서 사용하는 가상 dom의 특성 때문에 화면에 바뀐 변수가 나오지 않는다.
하지만 이 기능을 사용하면 react가 상태 변화를 감지하고
값을 업데이트 해준다.

2. useEffect
특정 시점에 코드를 실행하는 hook.
화면 처음 켜졌을 때 / 값이 바뀌었을 때 / 렌더링 될 때 실행
등등을 가능하게 해준다.

위 countapp에서는 count가 일정 수준에 도달시 코드를 실행..
이런 식으로 사용이 가능하다.
